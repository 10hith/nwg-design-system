Component Library

19 reusable HTML fragments organised by visual role. Copy any snippet into a slide's html_body field. All styles use design tokens — no hardcoded hex values.

Component rules for AI

Every component uses only var(--token) variables from nwg-tokens.css — never raw hex. Copy the snippet, adapt the content in data-slot attributes, assemble freely. Each comment is a placeholder for future UX/UI guidance.
