# s-matrix — Preset Recipe

**Components used:** title-block + data-table (with pill column headers and tinted rows) + optional highlight column

**Use verbatim when:** 2–4 entity columns × 3–6 attribute rows with short cell values

**Deviate (use Mode A) when:** cells contain long prose, you need sparklines in cells, or you have more than 4 columns (split the slide instead)
