# s-3col — Preset Recipe

**Components used:** title-block + divider-bar (banner) + grid-3col (3× callout-card) + optional footer pill

**Use verbatim when:** exactly 3 equal-weight pillars each with a heading and 3–5 bullets — no more, no less

**Deviate (use Mode A) when:** 4+ columns, unequal weighting, you want icons with real visuals, or you want data (stats, charts) inside the columns
