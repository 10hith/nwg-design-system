# s-tree — Preset Recipe

**Components used:** title-block + parent node (dark card) + bracket connector + 3–5 child nodes + optional product grid

**Use verbatim when:** one parent decomposing into 3–5 equal siblings, optionally with a product grid beneath

**Deviate (use Mode A) when:** hierarchy is more than 2 levels deep, siblings vary wildly in size, or you want to annotate individual branches with data
