# s-stack — Preset Recipe

**Components used:** title-block + 3–5× bullet-row (gold dot + statement)

**Use verbatim when:** 3–5 parallel assertions of equal weight with no supporting data

**Deviate (use Mode A) when:** items have different weights, need sub-bullets, include supporting stats, or you want a more visual treatment (e.g. callout-cards, icon-pills alongside text)
